## База данных (PostgreSQL)

Данные хранятся в PostgreSQL (скрипты в папке `db`). Файл `db.json` оставлен в репозитории как архив, но больше не используется (`json-server-auth` отключён из основного запуска).

Пароль во всех конфигурациях — `123456`.

Настройка:

1. Скопируйте `.env.example` в `.env` (параметры подключения к PostgreSQL, пароль `123456`).
2. Перенесите данные из `db.json` в базу: `npm run db:import`
   (или примените готовые скрипты схемы и данных: `npm run db:migrate`)
3. Запустите API-сервер: `npm run server` (http://localhost:4000)
4. Запустите фронтенд: `npm run dev`

Для входа можно использовать любой аккаунт из `db.json`, например `ivanov@email.com` с паролем `123456`.
